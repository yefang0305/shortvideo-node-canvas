# 产品介绍 HTML Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a standalone architecture-first product introduction page for the short-video node canvas workbench, with a dynamic first-viewport demo.

**Architecture:** Add one static HTML file at `showcase/product-intro.html`. The page is self-contained with embedded CSS and no build step; it presents a two-shot Codex-to-workbench animation in the hero, keeps the architecture chain visible, then explains capabilities, usage, audience, and implementation details.

**Tech Stack:** Static HTML, embedded CSS, vanilla JavaScript only if needed for small visual polish.

---

## File Structure

- Create: `showcase/product-intro.html`
  - Responsibility: standalone product introduction page that can be opened directly in a browser.
- Contains semantic HTML sections, embedded CSS, responsive layout, dynamic demo markup, and architecture diagram markup.
- Read only: `docs/superpowers/specs/2026-06-01-产品介绍HTML-design.md`
  - Responsibility: source of truth for page positioning, section order, and acceptance criteria.
- Optional read only: `showcase/index.html`
  - Responsibility: visual reference for the existing dark engineering style.

No application logic, MCP code, runtime code, config files, README files, or existing showcase index files are modified.
