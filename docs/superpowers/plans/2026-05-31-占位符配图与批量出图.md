# 占位符配图 + 批量出图 Implementation Plan

> 实现交给 Codex+DeepSeek（codex_with_cc 工作流）。TDD，本机无 pytest 用临时 runner，Python313。
> spec：docs/superpowers/specs/2026-05-31-占位符配图与批量出图-design.md

**Goal:** 配图方案带 `[[IMG:n]]`/`[[COVER]]` 占位符、图片精确落位；文生图一次出 N 张。

---

## Task 1 · illustrator 专属执行器（占位符 + id'd prompts）
**Files:** `app/models.py`（节点 def）、`app/runtime/tool_executor.py`（执行器）、`tests/test_illustrator.py`
- models.py：`skill_baoyu_article_illustrator` 去 `skill_binding`，`outputs=["article_text","image_prompts"]`，参数 `执行模式/配图数量/补充指令`。
- tool_executor：`execute` 加分支 → `_run_article_illustrator`：读 article_text → 调 `load_agent_settings` 模型 → 强制 JSON `{anchors:[{id,kind,prompt,anchor}], }` → 执行器按 anchor（章节标题/段落首句）在**完整原文**插 `[[IMG:n]]`/`[[COVER]]` → 落 article_text(.md) + image_prompts(id'd) 两端口。
- 测试：mock `_chat_completion_content` 返回固定 JSON → 断言两端口产物 + 占位符插进完整原文正确位置。

## Task 2 · 文生图 batch 多图
**Files:** `app/runtime/tool_executor.py`（image_gen 执行路径）、`tests/test_image_gen_batch.py`
- 检测 image_prompts 结构化 id 列表 → 每条写 .md + 构造 baoyu `batch.json`（tasks 带 id/promptFiles/image/provider/model/ar）→ `bun main.ts --batchfile batch.json --json` → 解析 stdout → `image_list.meta.images=[{id,path}]`，items=[paths]。
- 兼容旧单 .md 单图路径。
- 测试：构造 N 条结构化 prompts → 断言 batch.json 结构 + meta.images 映射（mock subprocess，不真调即梦）。

## Task 3 · 装配占位符插入
**Files:** `app/runtime/tool_executor.py`（`_assemble_markdown_with_images` / `_run_wechat_article_assemble`）、`tests/test_assemble_placeholder.py`
- 文章含 `[[IMG:id]]` → 替换为对应 id 图 `![](path)`（用 image_list.meta.images）；`[[COVER]]` → 取出作封面、占位符删除。
- 未匹配占位符删除不报错。无占位符 → 回退现策略（不回归）。
- 测试：带 `[[IMG:1]][[COVER]]` + meta.images → 断言插对位置 + cover 取出 + 旧路径兼容。

## Task 4 · 端到端 + 节点库刷新
- custom_nodes.json：illustrator 若仍在 custom，迁为 builtin（models.py）或更新其 def（去 skill_binding）。
- 全套测试绿；offscreen GUI 加载无误。
- 手动（可选 @真机）：md → 配图 → 文生图(即梦) → 装配 → 上传 验证图文落位。
