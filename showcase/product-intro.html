它能干啥

// usage

它怎么用

GUI 上手路径很短，五步跑通一条链路。同时外部 Agent 可以完全绕过 GUI，通过 MCP 工具直接操控画布。

1
从左侧节点库拖节点到画布
或双击节点快速添加。节点库列出所有可用节点及其能力摘要。
2
在右侧参数面板配置节点参数
参数控件化：执行模式下拉、数字、布尔、文件/目录选择，按节点声明自动生成。
3
从输出端口连接到下游输入端口
系统按端口 Schema 校验兼容性，类型不匹配时拒绝连线并给出契约级原因。
4
选择模拟或真实执行
默认模拟，安全预览。真实执行时高风险节点和行动节点需要显式确认。
5
运行当前节点、从此继续，或运行全部流程
单节点调试、按依赖链触发下游、全流程执行——三种粒度按需选择。
Agent 用法：外部 Agent 通过 video-workbench MCP 调用工具（add_node / connect / set_params / run_node / run_chain / run_all / get_output / create_skill_node 等 15 个工具）。画布状态以 workflows/active.json + rev 为单一真相源，GUI 通过 QFileSystemWatcher 监听外部变更并实时重绘——Agent 的操作在画布上即时可见。

// implementation

它怎么实现

系统由四个解耦的层组成：GUI 画布层、节点协议层、无 Qt 运行引擎层、MCP 控制面层。每层有自己的职责边界，通过 workflows/active.json + rev 同步状态。

app/ui/

PyQt 桌面界面

无限画布、节点库面板、参数控件面板。拖拽/双击添加节点，选中/移动/连线/删除。QFileSystemWatcher 监听外部 MCP 变更，rev 比对后防抖重载。

app/manifest.py

厚 Manifest 节点声明

每个节点自描述：端口数据契约 Schema、参数含义与校验、何时使用、典型上下游、产物样例、能力标签、触发关键词。既是人类文档也是 Agent 可读协议。

app/runtime/runner.py

WorkflowRunner 运行引擎

无 Qt 依赖的纯 Python 运行编排层。支持单节点运行、从此继续（按依赖链触发下游）、运行全部（无依赖节点并行）。

app/runtime/tool_executor.py

ToolExecutor 真实执行

真实节点和 skill 节点的执行入口。节点声明与执行逻辑解耦：新增能力优先通过 Manifest / Skill 节点接入，不写业务代码。

app/mcp/server.py

FastMCP stdio 服务

暴露 15 个 MCP 工具：list_nodes / add_node / connect / set_params / run_node / run_chain / run_all / get_output / get_logs / create_skill_node / reload_nodes / get_external_actions / complete_external_action 等。仅本机 stdio，不暴露网络端口。

app/mcp/store.py

工作流仓库

active.json + rev 单一真相源。负责工作流的读写、版本号管理和外部改动检测。GUI 和 MCP 两边都通过它操作画布状态。

workflows/active.json

GUI 与 MCP 同步中介

当前画布状态的序列化表示，带 rev 版本号。GUI 写入变更时 rev 自增；MCP 修改后 rev 变化触发 GUI 重绘。

config/credentials.json

集中凭证管理

统一凭证文件（gitignored），节点按 {cred:服务.字段} 引用。MCP 不回传密钥，凭证只在脚本子进程注入。

skill_node (3 modes)

Skill 节点三模式

text：skill 正文当 system prompt 调 LLM。image：生成 codex_imagegen 外部动作请求，Codex 生图后回填 image_list。script：跑 skill 自带脚本（bun / python），{input}/{output}/{cred:*} 占位注入。

声明与执行解耦
新增能力优先通过 Manifest / Skill 节点接入，不写业务代码。造声明（写 Manifest）与跑执行（通用 skill_node 执行器）分离。只有无 skill 也无现成工具时，才人工写一次连接器节点。
文生图走 Codex 外部动作协议
文生图节点生成 codex_imagegen 请求，节点状态变为 waiting_external；Codex 用内置 imagegen 生图后，通过 complete_external_action 回填 image_list。只有显式开启「允许第三方备用」时才走第三方 provider。
高风险动作确认闸门
高风险真实节点需显式 confirm=true 才执行。MCP 仅本机 stdio，无网络端口。凭证集中、gitignored、不回传。造节点默认 write=false 预览。
// safety boundary

安全边界

本地优先、显式确认、不暴露凭证——安全不是附加功能，是架构内建的约束。

🔒
仅本机 stdio
MCP 服务不暴露网络端口，外部 Agent 只能通过本机进程通信接入。
✅
高风险动作需确认
发布、下载、真实执行等操作需要显式 confirm，不会静默触发。
🔑
凭证不回传
config/credentials.json gitignored，{cred:} 占位只在脚本子进程注入，MCP 工具不返回密钥内容。
👁️
预览优先
造节点默认 write=false 预览，确认后才写入。外部动作在画布上实时可见，不会黑盒运行。
